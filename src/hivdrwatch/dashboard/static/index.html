SAWA · open HIV-1 drug-resistance surveillance

Resistance calls on public HIV-1 pol sequences

SAWA is an open, reproducible pipeline that ingests public HIV-1 pol sequences, calls resistance with Stanford HIVdb Sierra, and publishes the denominator behind every figure. This page summarises one data vintage; it makes no live calls and is drawn from a committed JSON file.

The cohort is public HIV-1 pol sequences retrieved by an East-Africa-targeted LANL/GenBank query. That names the query, not the sequences. of ingested accessions returned a Sierra result ( did not), giving resistance calls across drugs in classes.

Geographic and subtype breakdowns are deliberately absent. The ingest provenance evaluation found that this vintage’s country and subtype fields were written from the wrong source: every country value reflects the search query rather than the record, and it counts 3,108 accessions that state a country outside the targeted region. Those views return after a provenance rebuild.

Resistance prevalence by drug class

A sequence counts as resistant to a class if any drug in it scores intermediate or high-level resistance in HIVdb. Classes are in manuscript order.

The denominator is “Sierra returned a score for this gene”. That is not the same as “the surveillance codons were sequenced”: the data carry no per-gene coordinates, so true codon coverage cannot be computed without re-calling Sierra, and a sequence that stops short of a codon counts as unmutated there. Only of sequences have integrase coverage, because most deposited pol sequences cover PR and RT only.

    Surveillance resistance mutations

    Sierra reports every variant relative to consensus, and the most frequent are natural polymorphisms, not resistance. Only positions and states on the surveillance list (Bennett et al. 2009, updated 2019) are counted, for protease (PR) and reverse transcriptase (RT).

    Integrase mutations are not shown. The vendored surveillance list predates the dolutegravir era: Bennett et al. 2009 has no integrase component, and the integrase block in the reference file is the raltegravir/elvitegravir-era list, missing R263K, G118R and E138K. Showing it would attribute to Bennett a list it does not contain.

    Counting convention: a mixture counts as carrying a surveillance mutation when any of its states is one. Where a mixture matches more than one state, it is attributed to a single one. That affects of observations ( of ), so at positions with several surveillance states a mutation’s count can be slightly understated.
